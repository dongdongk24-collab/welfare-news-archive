최신 상태 확인

매일 오전 8시에 RSS 기반 자동 수집 결과가 저장됩니다. 자동 수집이 안 됐거나 며칠 놓쳤을 때는 직접 실행하면 저장되지 않은 날짜를 어제까지 순서대로 채웁니다.

수집 실행 후 보통 1~3분 뒤 새로고침하면 새 날짜가 보입니다.
